## Portfolio-Projects
This repository showcases my projects across multiple domains, including Data Analysis, Machine Learning, Natural Language Processing (NLP), and Artificial Intelligence (AI). Demonstrating practical applications, end-to-end workflows, built using Tensorflow,Sklearn and python.


### Current Projects 
- **Network Attack Classification** - we used deep neural network to detect IOT network attacks on server, after evaluation we reached a accuracy of 99%.
- **House Price Prediction** - For House price prediction we used multiple algorithms like xgboost, svr, RandomforestRegressor, and neural network each model was evaluated and code for all the models is included in the notebook.
- **Tesco Customer & Store Analysis (Power BI)** - built a Power BI dashboard on Tesco's customer, transaction, loyalty and store data to analyse churn, retention, loyalty tiers and high value customers (CLV), using DAX measures and a multi page report to give retention and promotion recommendations.
- **US Stock Market Segmentation** - scraped pricing, return and 52 week performance data for 20,000+ US stocks from Stooq, cleaned and engineered features, and segmented/clustered the stocks by liquidity, short and long term return behaviour.
